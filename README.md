# ПЗ магазину «Рошен» — варіант 13

![tests](https://github.com/mishachernika/roshen-lr6/actions/workflows/tests.yml/badge.svg)

Навчальний програмний продукт для дисципліни «Конструювання програмного
забезпечення» (ВФК НУХТ, Луцьк). Автор: Чернік Михайло, група ІПЗ-41.

Спіральна модель ЖЦ: ЛР1 — план, ЛР2 — вимоги, ЛР3 — структури даних,
ЛР4 — реалізація та метрики, ЛР5 — тестування та відлагодження,
ЛР6 — документація результатів розробки та візуальна оболонка.

## Функціональність

- `calc_discount(total, is_member)` — сума до сплати зі знижкою за обсягом
  (0 % до 500 грн, 5 % від 500 до 1000 грн, 10 % понад 1000 грн) та знижкою
  за карткою постійного клієнта +3 %.
- `process_order(order, stock, prices, is_member)` — валідація замовлення
  (товар у прайс-листі, кількість додатна й не більша за залишок),
  розрахунок суми зі знижкою та списання товару зі складу; повертає `None`,
  якщо замовлення відхилено (склад при відмові не змінюється).
- `gui.py` — візуальна оболонка (Tkinter, ЛР6) поверх тієї самої логіки:
  форма замовлення, панель суми, повідомлення про відмову, довідка (F1).

## Запуск

```bash
python gui.py                # візуальна оболонка (Tkinter) — основний режим касира
python roshen_shop.py        # демонстраційний консольний сценарій: «До сплати: 680.8»
                             # (імпорт модуля теж виконує main() — відомий недолік)
python metrics.py            # метрики Холстеда та Спен
python -m unittest discover -s tests -v   # 34 тести
```

Вимоги: Python 3.8+, лише стандартна бібліотека; для GUI — Python із
підтримкою Tkinter (Windows/macOS — є у встановлювачі; Linux — пакет
`python3-tk`). ОС: Windows / Linux / macOS.

## Тестування (ЛР5–ЛР6)

| Пакет | Рівень | Підхід | Тестів |
|-------|--------|--------|--------|
| T1 (`test_shop.py`) | модульне | білий ящик | 8 |
| T2 (`test_system_blackbox.py`) | системне функціональне | чорний ящик: еквівалентне розбиття, граничні значення | 14 |
| T3 (`test_scenarios.py`) | інтеграційне сценарне | сірий ящик: наскрізні сценарії | 4 |
| T4 (`test_gui.py`) | логіка оболонки gui.py | headless: валідація причин відмови, панель суми, зв'язок із бізнес-логікою | 8 |

Разом 34 тести; покриття `roshen_shop.py` з обліком гілок — 96 %
(`gui.py` виключено з покриття через `.coveragerc`, бо потребує екрана):

```bash
python -m pip install coverage
python -m coverage run -m unittest discover -s tests
python -m coverage report -m
```

Тести ST-12, ST-13 — регресійні відтворювачі дефектів D-01 (від'ємна
кількість приймалася, залишок зростав) і D-02 (нульова кількість
приймалася), виправлених валідацією кількості в `process_order`.

## Документація (ЛР6)

- `docs/ТЗ_Магазин_Рошен.md` — технічне завдання: портрет користувача,
  вимоги R-01–R-06, палітра/шрифти з контрастом WCAG, схема даних
  (кандидат у таблиці БД), реалізація GUI у `gui.py`;
- `docs/Меню_і_діалоги.md` — режими роботи й точки повернення, схема меню з
  піктограмами, макети діалогів (реалізовані у `gui.py`), гарячі клавіші
  (Ctrl+Enter, Esc, F1), підказки, повідомлення про відмову;
- `docs/Керівництво_користувача.md` — встановлення, запуск (GUI і консоль),
  сценарії розрахунку, формати даних, повідомлення, обмеження версії;
- `docs/HELP_Магазин_Рошен.md` — довідка: введення, знижки, умови відмови,
  значення результату, повідомлення про помилки.
