# Керівництво користувача — ПЗ магазину «Рошен»

Версія 1.0 (спіраль ЛР5/ЛР6). Документ призначений касиру торгової точки.

## 1. Призначення

Програма обчислює суму до сплати за замовлення: знижку за обсягом (0/5/10 %)
та за карткою постійного клієнта (+3 %), перевіряє замовлення і списує товар
зі складу тільки після успішного прийняття.

## 2. Вимоги до комп'ютера

- ОС: Windows, Linux або macOS.
- Python 3.8 або новіший, без сторонніх бібліотек.
- 1 МБ вільного місця на диску.

## 3. Встановлення

Скопіюйте файли продукту (`roshen_shop.py`, каталог `tests/`) у каталог на
диску. Окремої установки не потребується.

## 4. Запуск

```bash
python roshen_shop.py
```

Очікуване виведення:

```
До сплати: 680.8
```

Це демонстраційний сценарій: замовлення {Конфети: 3, Торт: 2} зі складу
{Конфети: 50, Торт: 20, Шоколад: 100}, картка клієнта є; сума
3·120 + 2·190 = 740 грн → знижка 8 % (5 % за суму понад 500 грн + 3 % картка)
= 59.2 грн → до сплати 680.8 грн.

## 5. Сценарії роботи

### 5.1 Розрахунок знижки за сумою

| Сума | Знижка | До сплати |
|------|--------|-----------|
| до 500 грн | 0 % | сума |
| від 500 до 1000 грн | 5 % | сума × 0.95 |
| 1000 грн і більше | 10 % | сума × 0.90 |

### 5.2 Картка постійного клієнта

Параметр `is_member` додає 3 % знижки до базової: наприклад, сума 965 грн з
карткою → 0.92 → 887.8 грн (див. ST-07).

### 5.3 Коли замовлення відхиляється

Програма повертає відмову (без зміни складу) у трьох випадках:

| Випадок | Приклад | Повернення |
|---|---|---|
| товар відсутній у прайс-листі | «Вафлі» | None (ST-08) |
| кількість більша за залишок | «Торт»: 21 при залишку 20 | None (ST-11) |
| кількість нульова або від'ємна | «Торт»: 0, «Торт»: −2 | None (ST-12, ST-13) |

При відмові залишки складу гарантовано не змінюються.

## 6. Формати даних

Замовлення, склад і прайс-лист передаються словниками виду
`{"Товар": кількість_або_ціна}`. Ознака картки — істина/хибність.
Результат: число з двома знаками після коми або None.

## 7. Повідомлення про результат

- «До сплати: N» — замовлення прийнято, товар списано зі складу;
- «Замовлення відхилено» — у трьох випадках з таблиці 5.3.

## 8. Обмеження поточної версії

- дистанційна робота з базою даних і архівом чеків не передбачена —
  стан складу живе в пам'яті під час одного запуску;
- товарові з прайс-листа гарантується запис у прайс-листі цін: якщо
  замовляєте товар, якого немає в прайс-листі цін, звертайтеся до адміністратора;
- замовлення на велику кількість позицій передається одним словником.

## 9. Зворотний зв'язок

Помилки зафіксовуйте репродуктором: вхідні дані + очікуваний результат.
Автоматизовані тести пакету `tests/` проганяються разом із
регресійним прогоном після кожної зміни (п. 3.1 ЛР5).
