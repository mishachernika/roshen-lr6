# Довідка (HELP-файл) — ПЗ магазину «Рошен»

Структура довідки: розділи відкриваються послідовно; кожен розділ — коротке
визначення + перелік пунктів. Призначена для перегляду поруч із роботою
програми (наприклад, у поділеному вікні редактора).

## Зміст

1. Призначення програми
2. Запуск
3. Введення — що вводить користувач
4. Обчислення знижки
5. Валідація і відмова
6. Результат і його значення
7. Повідомлення про помилки
8. Вкладки графічної оболонки (gui.py)

## 1. Призначення

Розрахунок суми до сплати за замовленням знижок за обсягом (0/5/10 %) і
картою постійного клієнта (+3 %), валідація замовлень, облік залишків складу.

## 2. Запуск

```
python gui.py                         # візуальна оболонка (Tkinter)
python roshen_shop.py                 # демонстраційний сценарій
python -m unittest discover -s tests  # усі 47 автоматизованих тестів
```

Команди запуску виконуються з кореня каталогу продукту.

## 3. Введення

| Параметр | Приклад | Опис |
|---|---|---|
| order (замовлення) | `{"Торт": 2}` | товар → кількість, шт |
| stock (склад) | `{"Торт": 20}` | товар → залишок, шт |
| prices (прайс-лист) | `{"Торт": 190}` | товар → ціна, грн |
| is_member (картка) | `True` | ознака постійного клієнта |

## 4. Обчислення знижки

Базова знижка за сумою: `total >= 1000` → 10 %; `total >= 500` → 5 %;
інакше 0 %. Ознака картки додає 3 %. Сума заокруглюється до 0,01 грн.

Приклади: 740 грн → 0.92 → 680.8 грн; 965 грн з карткою → 887.8 грн.

## 5. Валідація і відмова

Відмова (повернення None, склад не змінюється) у трьох випадках:

| Умова | Перевірка в коді |
|---|---|
| товар невідомий | `name not in stock` |
| кількість понад залишок | `stock[name] < order[name]` |
| кількість не перевищує нуля (нуль, від'ємна) | `order[name] <= 0` |

## 6. Результат

Успіх — сума до сплати (float, 2 знаки); відмова — None.
Текстове повідомлення (демонстраційний режим): «До сплати: N» або
«Замовлення відхилено».

## 7. Повідомлення про помилки

- `KeyError` при зверненні до `prices[name]` означає неузгодженість довідників
  (товар у складі, але не в прайс-листі цін) — сигнал адміністратору;
- `AssertionError` у тестах — порушення вимог R-01–R-06; репродуктор
  зафіксовуйте у вхідних даних тесту.

## 8. Вкладки графічної оболонки (gui.py)

Головне вікно «Магазин «Рошен» — каса» має три вкладки:

1. **Нове замовлення** — вибір товару і кількості, кнопка «Додати в чек»
   наповнює кошик (таблиця праворуч); панель показує «Сума → знижка →
   ДО СПЛАТИ»; «Оформити (Ctrl+Enter)» списує склад і додає чек у вкладку
   «Чеки»; «Скасувати (Esc)» очищає форму і кошик.
2. **Склад** — залишки з статусом (рядок «низький залишок» при < 10 шт
   підсвічено) і поповнення: товар + кількість + «Поповнити складу».
3. **Чеки** — історія оформлених замовлень (№, час, перелік товарів,
   знижка, сума) і виручка за зміну.

Гарячі клавіші: Ctrl+Enter — оформити; Esc — скасувати; F1 — ця довідка.
